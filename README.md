# Here, Kitty! — A tiny cat on your desk

> 내 책상 위에 사는 작은 고양이를 먹이고 쓰다듬고 재우며 키우는 MR 펫 육성 앱

| 항목 | 내용 |
|---|---|
| 만든 사람 | 송은빈 |
| 플랫폼 | Meta Quest (Android) |
| 엔진 | Unity 6000.3.15f1 · URP |

---

## 1. 앱 이름

**Here, Kitty!**

## 2. 한 줄 소개

현실 책상 위를 돌아다니는 아기 고양이를 돌봐서 어른으로 키우는 MR 펫 육성 앱.

## 3. 사용한 XR 기능

| 기능 | 쓰는 곳 |
|---|---|
| **패스스루** (AR Foundation · Meta OpenXR) | 현실 방 위에 고양이와 소품을 띄움 |
| **평면 인식 + 분류** (책상 · 바닥) | 책상 평면은 고양이 생활 범위, 바닥 평면은 간식 숨기는 곳 |
| **레이캐스트** | 컨트롤러로 책상을 가리켜 고양이 집 놓을 자리 지정 |
| **앵커** | 놓은 고양이 집을 현실 위치에 고정 |
| **Scene 권한** (`USE_SCENE`) | Space Setup에 등록한 책상 · 바닥 정보 사용 |
| **XRI 잡기** (Grab) | 먹이 · 방석 · 간식을 집어서 옮기기 |
| **XRI 소켓** (Socket) | 먹이를 밥그릇에 넣기 |
| **햅틱** | 쓰다듬을 때 컨트롤러 진동 |
| **XR UI** (World Space Canvas + 레이) | 시작 · 결과 화면, 버튼 |

## 4. 주요 기능

### 책상 위에 사는 고양이
- 컨트롤러로 책상을 가리키고 트리거를 누르면 그 자리에 고양이 집이 놓이고 고양이가 나타난다.
- 고양이는 **인식된 책상 평면 안에서만** 돌아다닌다. 가장자리에 다다르면 멈칫하고 돌아서서 떨어지지 않는다.
- 집 · 밥그릇 · 상자 같은 소품은 피해서 다닌다.

### 돌봄
| 행동 | 조작 | 고양이 반응 |
|---|---|---|
| 먹이 주기 | 상자에서 먹이를 집어 밥그릇에 넣기 | 밥그릇으로 걸어가서 먹기 |
| 쓰다듬기 | 컨트롤러로 머리를 문지르기 | 좋아하는 표정, 하트, 진동 |
| 재우기 | 졸려할 때 방석을 옆에 놓아 주기 | 방석 위로 폴짝 올라가 자기, 골골 소리 |
| 무시하기 | 오래 돌보지 않기 | 시무룩한 표정, 보채는 야옹 소리 |

- 상태값 3개(**배고픔 · 기분 · 졸림**)가 시간에 따라 변하고, 고양이 머리 위 아이콘과 **표정**으로 보인다.
- 돌봄이 필요하면 아이콘이 통통 튀어서 알려 준다.

### 성장 3단계
- 잘 돌보면 성장 게이지가 차서 **아기 → 어린이 → 어른**으로 자란다.
- 자랄 때마다 몸이 커지고, 반짝이 효과와 축하 문구가 나오고, **할 수 있는 행동이 늘어난다.**

| 단계 | 할 수 있는 행동 |
|---|---|
| 아기 | 걷기 · 먹기 · 자기 · 엎드려 졸기 |
| 어린이 | + 다가가면 인사하기 · 쓰다듬으면 좋아하기 |
| 어른 | + 땅 파기 · 앉기 · 기뻐서 점프하기 |

### 간식 찾기 이벤트 (어른 단계)
- 고양이가 땅을 파면 **방 바닥 어딘가, 내 시야 밖**에 간식이 숨겨진다.
- 반짝이와 반짝 소리를 따라 실제로 방을 돌아다니며 찾아서, 고양이 바로 앞에 내려놓아 주면 받아먹는다.

### 시작부터 엔딩까지
- **시작 화면** → **집 배치** → **육성** (처음 하는 행동마다 안내 문구와 안내 화살표) → **엔딩**
- 엔딩: 다 자란 고양이가 탐험가 차림(모자 · 가방)으로 인사하고 책상 가장자리로 떠난다.
- **결과 화면**: 돌본 시간 · 먹인 횟수 · 쓰다듬은 횟수, 처음부터 다시 하기

## 5. 느낀점

에디터 시뮬레이터에서 잘 되던 것도 헤드셋에서는 거리감 · 손 위치 · 공간 크기가 달라서, 실기기에서 자주 테스트하는 게 중요하다는 걸 느꼈다.
기능을 필수 / 목표 / 여유로 나눠 두고 필수부터 끝까지 완성한 덕분에, 짧은 일정 안에 처음부터 엔딩까지 이어지는 앱을 만들 수 있었다.
효과음, 안내 화살표, 팝 효과 같은 작은 연출이 들어가자 같은 기능도 훨씬 살아 있는 느낌이 들었다.
